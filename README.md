# Mission Space — Global Space Missions Analysis

# Project Overview

Mission Space is a data analytics project that explores global space missions from 1957 to 2022.

The project uses MySQL for data exploration and analysis and **Microsoft Power BI** to clean, transform, visualize, and present insights through an interactive dashboard.

# Project Objectives

- Explore historical trends in global space missions.
- Analyse mission success and failure outcomes.
- Identify companies with the highest number of missions.
- Examine rocket usage and launch locations.
- Understand how space mission activity has evolved over time.

## Tools & Technologies

- **MySQL** — Data exploration and SQL analysis.
- **Microsoft Power BI** — Interactive dashboard development.
- **Power Query** — Data cleaning and transformation.
- **CSV** — Dataset format.

## Key Project Findings

- **Total Missions:** 4,630
- **Successful Missions:** 4,162
- **Overall Success Rate:** 89.89%
